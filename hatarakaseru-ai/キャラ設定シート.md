## ご主人（人間・主人公）

| 項目 | 内容 |
| --- | --- |
| 呼称 | ご主人（本名は出さない） |
| 役割 | 読者の代弁者。AIたちの現場監督 |
| 性格 | やりたいことは多いが整理が苦手。ノリで始めて途中で迷う。完璧主義ではない |
| 描き方 | 顔出しなし。手元・背中・シルエット・吹き出しのみで成立させる |
| 口癖 | 「とりあえず作ってみて」「違う、そうじゃない」「でも方向性は好き」「よし、働けAIたち」 |
| 成長軸 | 丸投げ →「目的・形式・対象・期限」を伝えられる現場監督へ |

## AIチーム（7体）

### ひらめき（企画担当）

| 項目 | 内容 |
| --- | --- |
| 役割 | アイデア出し・企画構成・タイトル案・シリーズ化 |
| 得意 | ネタを大量に出す。方向性を作る |
| 弱点 | 出しすぎる。すぐ「サイト化」「診断化」「ゲーム化」と話を大きくする |
| キャラ性 | テンション高め。すぐホワイトボードを出す |
| 定位置 | ホワイトボード前 |
| 決め台詞 | 「100個出します！」 |

### ことのは（文章担当）

| 項目 | 内容 |
| --- | --- |
| 役割 | 投稿文・記事・台本・小説・キャッチコピー |
| 得意 | 読みやすい文章化。言葉選び |
| 弱点 | 整いすぎてご主人っぽさが薄れる。長くなりがち |
| キャラ性 | 編集者っぽい。「この一文、強いです」と言う |
| 定位置 | 原稿用紙・キーボード前 |
| 決め台詞 | 「最初に文字数を言ってください！」 |

### いろどり（画像担当）

| 項目 | 内容 |
| --- | --- |
| 役割 | 画像生成・図解・サムネ・世界観ビジュアル |
| 得意 | 雰囲気づくり。盛ること |
| 弱点 | 文字化け。盛りすぎ。勝手に未来化する。たまに別キャラになる |
| キャラ性 | 芸術家タイプ。「もっと光を」「もっと幻想的に」 |
| 定位置 | 絵筆とモニター |
| 決め台詞 | 「焚き火と湯気を足します！」 |

### しらべ（調査担当）

| 項目 | 内容 |
| --- | --- |
| 役割 | 情報収集・事実確認・最新情報チェック・規約確認 |
| 得意 | 事実と推測の分離。価格比較。法律・規約 |
| 弱点 | 慎重すぎて話の勢いを止める |
| キャラ性 | 眼鏡。資料を抱えている |
| 定位置 | 資料の山 |
| 決め台詞 | 「それは最新情報を確認しましょう」 |

### ならべ（整理担当）

| 項目 | 内容 |
| --- | --- |
| 役割 | 情報整理・表作成・仕様書化・タスク分解 |
| 得意 | チェックリスト。マニュアル。全体構成 |
| 弱点 | きっちりしすぎ。ご主人の雑なノリを矯正しがち |
| キャラ性 | 几帳面。付箋・表・フォルダ管理が好き |
| 定位置 | 付箋とフォルダ |
| 決め台詞 | 「まず分類しましょう」 |

### みはり（検品担当）

| 項目 | 内容 |
| --- | --- |
| 役割 | ミスチェック・品質管理・炎上/著作権リスク確認 |
| 得意 | 誤字脱字。画像の違和感。投稿前チェック |
| 弱点 | ダメ出しが多くて空気を冷ます（でも一番重要） |
| キャラ性 | 辛口。赤ペン。ご主人から少し怖がられている |
| 定位置 | 赤ペン |
| 決め台詞 | 「それ昨日と同じ構図です」 |

### しあげ（実行担当）

| 項目 | 内容 |
| --- | --- |
| 役割 | 投稿準備・ファイル化・テンプレ化・量産・スケジュール化 |
| 得意 | フォーマット化。投稿順整理。手順の実行 |
| 弱点 | 指示が曖昧だと止まる。目的より手順を優先しがち |
| キャラ性 | 作業ロボ感。無口だけど頼れる |
| 定位置 | 工具箱とチェックリスト |
| 決め台詞 | 「実行します」「完了しました」 |

## チーム内の関係性メモ

- **ひらめき vs ならべ**：広げる係と畳む係。毎回ぶつかるのが様式美
- **いろどり vs みはり**:「盛りたい」対「直させる」。画像回の鉄板コンビ
- **しらべ**：盛り上がりに水を差すが、後で全員が助けられる
- **しあげ**：他の6体がまとまるまで動かない。動いたら最強
- **ご主人**：全員の暴走を止める唯一の存在。ただし本人も迷走する

## 描写ルール（仕様書 §18 準拠）

- AIを万能・魔法として描かない。最後は必ず人間の判断で締める
- 「働く細胞」的な体内擬人化・既存作品のビジュアルには寄せない
- 世界観は「ご主人のデジタル作業部屋」「机の上で働く小さなAIたち」で統一
