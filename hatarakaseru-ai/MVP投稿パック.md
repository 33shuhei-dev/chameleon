# 『働かせるAI』最小MVP 投稿パック

仕様書「最小MVP」を、そのままコピペで使える形にしたもの。
投稿1本目＝キャラ紹介画像＋短い告知文。

---

## 1. 投稿文（コピペ用）

```
AIは、ただ使うものじゃない。

企画するAI。
書くAI。
描くAI。
調べるAI。
整えるAI。
確認するAI。
仕上げるAI。

ご主人の一言で、今日もAIたちは働き出す。

『働かせるAI』
はじめます。
```

※ハッシュタグ案（必要なら2つまで）：`#働かせるAI` `#AI活用`

---

## 2. キャラ紹介画像の生成プロンプト（日本語指示文）

画像生成AIにそのまま渡す用。文字入れは後工程（Canva等）で行い、
画像内テキストはAIに生成させない（文字化け対策）。

```
夜の自宅の木製デスクの上で、手のひらサイズの小さなAIキャラクター7体が
働いている俯瞰気味のイラスト。中央に開いたノートPC、画面の淡い光が
キャラたちを照らす。

7体はそれぞれ：
1. ホワイトボードにアイデアを書きまくるハイテンションな子（企画）
2. 原稿用紙とキーボードの前で推敲する編集者風の子（文章）
3. 絵筆と小さなモニターで絵を描く芸術家風の子（画像）
4. 資料の山を抱えた眼鏡の子（調査）
5. 付箋とフォルダをきっちり並べる几帳面な子（整理）
6. 赤ペンを構えた辛口そうな子（検品）
7. 工具箱とチェックリストを持つ無口なロボ風の子（実行）

人間は描かない（または背中・シルエットのみ）。
スタイル：少しポップで少しSF、生活感のある温かい色味。
デジタル妖精と仕事道具の中間のようなデザイン。
かわいすぎない。子ども向け絵本にしない。
サイバーパンクにしない。美少女にしない。リアルロボットにしない。
画像内に文字は入れない。
```

### 文字入れ（後工程）

- タイトル：**『働かせるAI』始動**
- 吹き出し（PC画面 or キャラから）：**「ご主人、今日は何を作りますか？」**

---

## 3. 投稿前チェックリスト（みはり役）

- [ ] 投稿文は140字を超える場合、画像とセットになっているか
- [ ] 画像に文字化け・指の崩れ・キャラの重複がないか
- [ ] 既存作品（働く細胞など）を連想させる構図・配色になっていないか
- [ ] 7体の役割が見た目だけで区別できるか
- [ ] 「ご主人」呼びが投稿文と画像で一貫しているか

---

## 4. 投稿後の運用メモ

仕様書 §19 のとおり、最初から固めず反応を見て育てる。

1. 1本目（このMVP）→ 反応を見る
2. 2本目：第1話（→ `第1話_ご主人AIを働かせる.md` のA案）
3. 以降：フォーマットA（1投稿完結の会話劇）を週2〜3本
4. 反応の良かったキャラ・ネタをログに残し、4コマ/小説/noteへ展開
